# Water-Tank-Overflow-Alarm-System
A simple and low-cost Water Tank Overflow Alarm System using the NE555 timer IC, resistors, and capacitors. It provides precise control of the tank’s water level without complex modules and efficiently triggers a buzzer alarm when the tank reaches its maximum level, preventing overflow and saving water.

## 🧰 Components Used
- NE555 Timer IC
- Anti-Corrosion Water Level Sensor with Ball Float Switch
- 7805 regulator IC
- 220 ohm resistor
- Terminal connectors
- Vero board/ Zero pcb board
- 470 Kohm resistor
- 100 Kohm resistor
- 3mm red led
- 5mm green led
- 2.2 uf Capacitor  
- 12v Buzzer
- 12v power supply
- 2 pin plug
- Wires
- Plastic casing

## 🧠 Working Principle
The working principle very simple. The system works as a astable multivibrator and we know that the astable multivibrator do not have any stable state which is the main advantage of this project. The motto is to generate a pulse train of finite width which is provided by the timer ic. 
A water level sensor is implanted inside the tank and it working based on the principle of a reed switch. I have implanted the sensor at desired water level of the tank, when the water level meets the desired level the sensor gets activated and completes the circuitry and immediately the buzzer gets activated. This is core working principle of the sytem.
